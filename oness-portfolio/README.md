# Aarunya Web Solutions — ONESS INFRA Portfolio

A responsive, static portfolio and print-ready brochure prepared for ONESS INFRA, Indore.

## Preview locally
Open `index.html` in a browser. No build step or package installation is required.

## Print / Save as PDF
Use the **Print / Save PDF** control, or the browser's Print menu. Choose A4 paper and enable background graphics for the intended colours. Print CSS hides browser controls and uses page breaks.
