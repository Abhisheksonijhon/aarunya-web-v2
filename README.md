# Aarunya Web Solutions V2

Responsive React + Vite website for Aarunya Web Solutions.

## Technology
- React
- Vite
- Lucide icons
- Responsive CSS

## Cloud deployment
The repository is connected to Vercel. Vercel should install dependencies
and run `npm run build`, publishing the `dist` directory.

## Local development
Requires Node.js and npm:
- `npm install`
- `npm run dev`
- `npm run build`

No local Node.js installation is required when using Vercel's cloud build.
